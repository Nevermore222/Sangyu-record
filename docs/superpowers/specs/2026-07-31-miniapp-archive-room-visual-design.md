# 桑榆录小程序视觉改造设计

## 目标

将工作人员端统一为“口述档案室”视觉语言，并修复现场采集页在手机窄屏中四个操作入口重叠的问题。改造不改变页面路由、接口、数据结构或采集行为。

## 视觉系统

- 页面底色：暖白纸色与纯白操作面，正文保持深墨色。
- 语义色：墨绿表示正常推进与已完成；砖红表示录音、待补充和风险提示。
- 排版：回忆录、项目与结果使用宋体标题；表单、列表与操作控件使用系统无衬线字体。
- 分隔：使用细线和留白建立层级；按钮、输入框和列表转角不超过 8rpx。
- 图像：只在登录页、工作台和结果页使用低对比度的本地静态背景图。图像不得覆盖文本或交互区域；档案、走访、采集与表单页不使用背景图。

## 页面范围

### 全局

在 `app.wxss` 中补充统一的色彩令牌、页面层级、表单、固定操作栏和背景工具类。每个页面继续通过局部样式控制其信息密度，不引入新的组件框架。

### 现场采集

- 采集入口改为 2 列 x 2 行的 `capture-tools` 网格，四个入口保持同等的最小点击高度。
- 每个入口放置简洁图形标记和单行标题。录音状态仅改变自身的色彩和标记形状，不改变网格尺寸。
- 物料队列、照片预览、备注和上传摘要依次纵向排列；底部“提交本轮分析”继续固定在安全区之上。
- 采用 `minmax(0, 1fr)` 网格轨道、`min-width: 0` 和受限行高，确保 320px 至常规手机宽度无横向溢出或文本遮挡。

### 工作台、档案与个人中心

- 工作台保留任务计数和优先项目，将背景图限制在顶部欢迎区后方，并添加纯色遮罩保证数字可读。
- 档案页使用紧凑搜索与筛选、明确的项目行边界和空状态；不在列表背景中使用图片。
- 个人中心保持信息行布局，用档案印章式头像标记增强身份辨识。

### 建档、走访、报告、工作流与结果

- 建档与走访准备维持一列字段流，统一步骤进度、授权区和选择控件的间距。
- 走访报告与工作流强化状态阅读顺序，不改变原有动作。
- 结果页以本地背景图和书册预览作为完成状态的视觉重点，PDF 操作始终使用高对比固定按钮。
- 登录页使用低对比本地背景图，保留最小化的身份校验和重试操作。

## 资源策略

新增少量自有位图资源到 `miniapp/assets/`：纸张纹理、工作台背景、结果页背景和登录页背景。资源应经过压缩，避免网络加载和第三方图片授权问题。不得使用远程图片 URL。

## 验证

1. 添加一个页面结构测试，断言现场采集工具使用 2 列网格、四个入口和防溢出约束。
2. 添加资源与页面引用测试，断言背景图仅被允许页面使用且资源路径为本地路径。
3. 执行 `npm test`、`npm run typecheck` 和微信开发者工具 `build-npm`。
4. 在开发者工具中以 320px 和常规 iPhone 宽度检查：现场采集入口不重叠，底部操作栏不遮挡备注和上传操作。

## 非目标

- 不修改后端、认证、上传、转写、智能体或知识库调用。
- 不新增远程图片服务、第三方 UI 库或动态主题配置。
- 不改变小程序信息架构与现有导航。
